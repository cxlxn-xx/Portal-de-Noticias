# Portal-de-Noticias
## Descripción
Portal de Noticias es un sitio web desarrollado con html y css que permite acceder a noticias de diferentes categorías. El proyecto busca ofrecer una experiencia de navegación sencilla y atractiva para los usuarios.

## Tecnologías Utilizadas:
- html
- css
- GitHub

## Estructura del Proyecto:
Portal-de-Noticias/
|--index.html
|--tecnologia.html
|--deportes.html
|--economia.html
|--musica.html
|--styles.css
|--README.md

## Instalación:
1. Clonar el repositorio:
   '''bash
   git clone https://github.com/cxlxn-xx/Portal-de-Noticias.git
   '''
2. Ingresar al directorio del proyecto:
   ''' bash
   cd Portal-de-Noticias
   '''
