# Portal-de-Noticias

Portal de Noticias  muestra las últimas noticias organizadas por temáticas. Cada sección tiene su propia página con noticias, imágenes y descripciones. El proyecto fue desarrollado de forma colaborativa usando Git y GitHub.
##  Cómo instalar y correr el proyecto
No requiere instalación de dependencias. Seguí estos pasos:
**1.** Cloná el repositorio:
git clone https://github.com/cxlxn-xx/Portal-de-Noticias.git

**2.** Entrá a la carpeta del proyecto:
cd Portal-de-Noticias

**3.** Abrí el archivo `index.html` en tu navegador:
- Doble clic sobre el archivo, o
- Arrastralo al navegador

>  Necesitás conexión a internet para que carguen las imágenes
